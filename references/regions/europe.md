# 欧洲、俄罗斯及独联体外贸获客研究

核实日期：2026-09-07。范围：公开官方平台说明、活动官网及注册查询入口；未注册、未入群、未发送消息、未采集成员名单。以下国别优先级为家纺四件套、酒店布草的业务判断，不是平台国别渗透率排名。

## 先按用途选入口

- 企业发现：Europages、wlw、Kompass、活动展商目录。回答“这个企业存在、经营什么”，不能直接回答“现在是否要采购”。
- 需求发现：EEN 的 Business request，以及企业自己发布且仍有效的采购/寻源公告。Business Offer 很可能是供应商找代理，不是进口需求。
- 行业关系：Heimtextil、Maison&Objet/MOM、Formland 等展会、专业内容、主办方撮合。线下参会、专业身份、对某个产品点赞，都不能单独证明采购意愿。
- 人员定位：LinkedIn 的公司与职业信息；Sales Navigator 的职能、资历、任职时间等筛选。XING 目前官方定位为 jobs network，应降级为德语区职业/雇主背景补充，而不是默认的主力采购社区。
- 联系承接：企业官网明确链接的业务邮箱、联系表单、企业社媒；俄罗斯场景可检查官方 VK 社区与 Telegram 业务入口。账号可被搜索到，不等于已同意接收商业消息。

## 各平台的具体动作

### Europages / wlw / Kompass

1. 先确定客户类型：进口商、品牌、分销商、家居连锁、酒店用品商、布草洗涤租赁商、项目集成商，不能只输产品词。
2. 用产品词与本地角色词定位公司，再查看其经营描述、品牌、服务国家、官网；平台提供的分类仅作初筛。
3. 阅读官网 Catalog / Brands / Wholesale / Private label / Hospitality / Supplier 页面，寻找商品结构、MOQ、仓库与批发条件等线索。
4. 单独标记制造商、经销商、品牌、零售商、潜在合作伙伴。只在出现进口、第三方品牌代理或贴牌采购证据时提高采购相关度。
5. Kompass 的付费数据与 EasyBusiness 不能写成全部免费；公开目录、营销产品说明和当前真实询盘是三件不同的事。数据授权也不能替代触达许可。

### EEN Partnering Opportunities

1. 进入官方机会页，选 `Business request`，输入 `textile`、`bed linen`、`hotel` 等关键词；查看国家与拟建立的合作类型。
2. 区分真正找供应商的请求、寻找经销/商业伙伴的请求，以及研发合作。`Supplier agreement` 也须结合正文判断谁供谁买。
3. 记录机会编号、发布时间/有效期（页面可得时）、产品/技术要求、预期合作伙伴与原文链接。
4. 依该机会的页面指引，经网络顾问或当地联络点表达兴趣；未获披露时不要编造匿名企业名称和采购联系人。
5. 无匹配请求时回退企业发现，不把“没有 RFQ”补写成“客户可能采购，等同需求”。

### LinkedIn / XING

1. 先有目标公司再找人。用公司、职能、地区、职位词筛选采购、品类、供应链及项目角色；Sales Navigator 官方确认高级筛选和部分套餐专属功能，不是所有账户都能使用。
2. 读最近职位、所属公司、职责；“Head of Sales”常是卖方销售，而不是采购决策人。小公司创始人可以是采购人，但需实证。
3. 企业 Page、职位履历、企业官网互证；单一自填履历不能单独确认为在职采购权。
4. 借共同活动、具体产品帖子或明确采购话题建立业务语境。只有符合平台/地区规则和对方接受方式时，才发送人工审核过的相关消息；不批量加人或私信。
5. XING 当前更适合补充雇主与职业信息，不沿用过时的“德国版 LinkedIn 所以必须主攻”判断。

### 展会、MOM 与专业社区

1. 分为“公开展商”“官方披露的访客企业”“匹配会预约对象”“明确询价者”四种证据级别。
2. Heimtextil 官网有 2026 访客企业名单节选 PDF 的入口，本次只核实该入口存在，未下载或读取 PDF、未提取名单；它不能证明访客当前采购。
3. MOM 可看家纺与酒店寝具类目、品牌内容和预约实体展会的介绍，但与品牌接触需账号。不是任何制造商都能直接看到所有买家的联系方式。
4. Trendz/showUP 官网说明参观需预注册及有效商会注册号；活动 App 具备会议预约。注册条件、收费和功能以当届要求为准，本次未注册或实际预约。
5. 公开行业内容先提供有用回应，如洗涤测试方法、包装尺寸、产品适配讨论；入群或参会以后仍应先读规则，不投放与讨论无关的广告。
6. 把品牌的 Stockists / Retailers / Distributors 链接作为上下游扩展线索；不将它们推定为“竞品客户正在更换供应商”。

### VK / Telegram

- VK：官方商务门户链接到 `vk.com/business`；本次社区页面呈注册/登录壳，未实测当前社区搜索筛选或消息按钮。可推荐在用户登录后检查社区类型、商品/帖子、官网反链与真实业务身份，但不能写成“已经验证具体群可私信采购”。
- Telegram：官方说明公开用户名可在 global results 搜索，也可用通用搜索框查聊天、消息、用户名；公开群用于协作/讨论，频道用于广播。不要把频道订阅人数或成员用户名当联系人清单。
- 先从企业官网找到 `t.me` 入口，再读频道简介、置顶内容、公开业务联系说明；同名账号可能冒名，Telegram 用户名本身不证明企业归属。
- 对方在公开群明确提出采购需求且规则允许业务回复时，先回答该需求；若要转私聊，先取得对方接受。仅关注过频道、可搜索到用户名或暴露电话号码，不代表同意营销。
- Telegram 官方明确，陌生人举报不想收到的消息可造成账户发送能力受限；部分陌生消息还可能要求 Stars。本次不发送、不支付、不导出群成员。

## 从背调走到开发

### 最小背调包

- 实体：法定名称、注册号、地址、官网域名与集团/子公司关系。英国用 Companies House；挪威用 Brreg；芬兰用 YTJ。其余国家定位本国官方登记入口，不把平台认证标志替代法定登记。
- 经营：产品页、批发条款、仓库/门店、第三方品牌关系、酒店项目案例。每条记录原文链接与观察日期。
- 人员：姓名、职责、在职时间线、职业/企业身份互证；只保留公开且与业务有关的联系途径。
- 需求：区分目录类别、讨论兴趣、历史参会、正在询价；将交期、规格、数量、交付国家等写为明确事实或待确认项。
- 税务：VIES 用于欧盟跨境 VAT 资格查询，不是信誉评分。官方说明 invalid 也可能因未激活跨境交易或登记尚未完成，不能直接判为诈骗。[E18]
- 交易：报价主体、合同主体、收款账户、发货/最终目的地一致性；账期信用评估、样品/检验要求另做，登记存续不等于付款能力。
- 风险：拒绝提供公司主体、催促向第三方私人账户付款、网址与邮箱域名不一致、文件/证书无法核验、索取异常费用时暂停；俄罗斯及转口场景检查适用的贸易限制与支付路线。

### 建联后的提问顺序

1. 确认负责范围：“您负责床品选品/采购，还是酒店项目用品？若不属于您的范围，可否告知官网公布的供应商申请入口？”
2. 确认产品与场景：“零售四件套还是酒店耐洗布草？主要尺寸、材料和销售档位是什么？”
3. 确认采购模式：“现货补货、定制系列、贴牌还是项目采购？新供应商是否仍在评审？”
4. 确认约束：“预估试单量、目标交付月、包装、测试与文件要求有哪些？”
5. 只给相关材料：零售渠道看 3 个适配 SKU 与批发条件；酒店渠道看规格、洗涤测试和补货机制；品牌客户看开发能力、设计边界及样品计划。
6. 达成一个下一步：规格表评审、样品、视频会议、展会预约之一。没有回复不升级多平台围追；跟进按对方允许的方式，拒绝/退订立即停止并记入 CRM。

### CRM 应保留的独立字段

`country`、`language`、`company_role`、`platform_type`、`company_url`、`profile_url`、`official_link_evidence`、`contact_role`、`observed_at`、`demand_status`、`demand_evidence_url`、`contact_permission`、`verification_status`、`next_action`、`do_not_contact`。

不要把“有联系方式”“有采购权”“有当前需求”“允许外联”压成一个 verified。一个公司可以实体真实、账号真实，但没有当前需求，也没有营销许可。
